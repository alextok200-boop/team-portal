填一次 GitHub Token，以后「加人 / 发内容」点「一键发布到仓库」就直接提交， 不用再手工下载文件、覆盖仓库、跑 git 提交。
① Token 怎么获取（一次性，大约 1 分钟）
打开 github.com/settings/personal-access-tokens/new
→ Token name：随便填，如 team-portal 自动提交
→ Expiration：选个有效期（如 90 天，到期回来换一把）
→ Resource owner：选 alextok200-boop
→ Repository access：选 Only select repositories，勾上 team-portal
→ Permissions → 展开 Repository permissions → 找到 Contents 选 Read and write （只给这一项就够；Metadata 会自动带上只读）
→ 点底部 Generate token，复制以 github_pat_ 开头的那串 —— 它只显示这一次，务必当场复制
→ 回到本页粘进下面「GitHub Token」框，点「保存配置」。 （经典 Token ghp_ 也能用，但必须勾整个 repo 权限、范围过大，不推荐。）
点「保存配置」时本站会真的试写一次（只产生一个游离对象，不改任何文件、不动分支）， 确认真能写才保存 —— 所以保存失败基本都是上一步 Contents 没给写权限。
② 安全说明：Token 只存在你这台浏览器里（localStorage）—— 不会写进仓库，也不会随导出的 users.json / content.json 泄漏出去。 怀疑泄漏就去 GitHub 撤销，回来点「清除配置」再填一把新的。
